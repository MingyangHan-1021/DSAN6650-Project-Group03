# 餐厅合作多智能体环境

## 1. 概述

两个智能体合作经营一家餐厅，共享同一份奖励：

- **厨师**：做菜、洗盘子
- **服务员**：带位、点单、上菜、清桌

两人需要围绕三个共享瓶颈协调：**干净盘子、出餐口、灶台**。

- 时间离散，1 步 ≈ 1 分钟，一回合 240 步（约 4 小时）
- 中心化版本：一个智能体同时控制两人
- 多智能体版本：两个智能体各自决策

## 2. 顾客流程

```
到达排队 → 带位 → 点主菜 → 厨师做菜 → 出餐口 → 上菜 → 用餐
   → （可能）点甜点 → 做甜点 → 上甜点 → 用餐
   → 付款（账单 + 小费）离开 → 清桌 → 脏盘子进洗碗池 → 厨师洗碗
```

## 3. 机制

### 3.1 多人组与桌型

- 顾客一组 1~4 人
- 桌子有两人桌和四人桌，一组只能坐进座位数足够的桌子
- 服务员选一张空桌带位，坐进去的是队列中**最早到达、且坐得下**的一组
- 取舍：小组坐大桌可以马上入座，但大组来了可能没桌

### 3.2 高峰时段

- 到达率随时间变化，模拟午餐高峰
- 用若干 [步数, 到达率] 点定义，中间线性插值
- 门口排队满了，新来的顾客直接离开

### 3.3 菜单

- 8 道主菜 + 3 道甜点，做菜时间和价格各不相同
- 每人点一道主菜，按权重随机
- 贵菜单价高，但占用灶台时间长

### 3.4 厨房

- 灶台最多同时做 3 道菜
- 厨师开一道菜只占用 1 步，之后菜在灶台上自己计时，厨师可以去做别的事
- 同一桌的菜，先做最费时的那道，让一桌的菜尽量同时出
- 每道菜开始做时占用一个干净盘子
- 洗碗一次最多洗 4 个，耗时 2 步

### 3.5 出餐口与凉菜

- 出餐口容量 6，正在灶台上的菜也预占位置
- 菜在出餐口放超过 3 步才被送到，算作**凉菜**，会降低小费

### 3.6 上菜

- 一桌的菜可以分批上
- 主菜**全部上齐**后才开始吃

### 3.7 甜点

- 吃完主菜后，每人有 25% 概率想要甜点
- 只要有一人想要，这桌进入甜点阶段，耐心重置为 15，等服务员来点甜点
- 甜点阶段等不及：主菜照付，直接离开
- 取舍：多赚一份甜点，还是早点翻台

### 3.8 耐心

- 每组初始耐心在 25~40 步之间随机
- 等待时耐心下降：排队和等点单每步 −1，等上菜每步 −0.5，用餐时不下降
- 主菜阶段耐心耗尽：不付钱离开，算作流失

### 3.9 小费

```
小费 = 账单 × 小费率
小费率 = 20% × 等待系数 × (1 − 0.5 × 凉菜比例)
```

- 等待时间 = 到达 → 主菜上齐（吃了甜点再加上甜点阶段的等待）
- 等待系数：10 步以内为 1，之后线性下降，60 步时降为 0
- 例：等 10 步内小费 20%，等 35 步约 10%，等 60 步以上为 0；全是凉菜再减半

### 3.10 盘子流转

```
干净 → 做菜 → 出餐口 → 桌上 → 清桌 → 洗碗池（脏）→ 洗碗 → 干净
```

盘子在桌上一直留到清桌，包括吃甜点期间的主菜盘。

## 4. 动作

N 为桌子数。锁定期间只能选 0（继续当前动作）。不合法的动作视为空闲。

### 厨师（N+2 个）

| 编号 | 动作 | 条件 | 耗时 |
|---|---|---|---|
| 0 | 空闲 / 继续 | 总是可以 | - |
| 1..N | 给第 k 号桌开一道菜 | 有待做的菜、有干净盘子、灶台有空、出餐口有空 | 1 步 |
| N+1 | 洗一批盘子 | 有脏盘子 | 2 步 |

### 服务员（4N+1 个）

| 编号 | 动作 | 条件 | 耗时 |
|---|---|---|---|
| 0 | 空闲 / 继续 | 总是可以 | - |
| 1..N | 带位到第 i 号桌 | 空桌，且队列中有坐得下的组 | 1 步 |
| N+1..2N | 给第 i 号桌点单 | 等点单（主菜或甜点） | 1 步 |
| 2N+1..3N | 给第 i 号桌上菜 | 出餐口有这桌的菜 | 1 步 |
| 3N+1..4N | 清理第 i 号桌 | 桌子待清理 | 1 步 |

medium 有 5 张桌子：厨师 7 个动作，服务员 21 个动作。

## 5. 观测

所有数值归一化到 0~1，维度与菜单长度无关。

| 部分 | 内容 |
|---|---|
| 每张桌子 | 状态、座位数、组人数、是否在甜点阶段、剩余耐心、用餐剩余时间、待做 / 在做 / 已出餐的菜数、已上菜比例、待做菜的总做菜时间、出餐口上的菜放了多久、已等待时间 |
| 门口排队 | 每个排队位置的人数和剩余耐心 |
| 厨房 | 干净盘子、脏盘子、出餐口占用、灶台占用、每个灶台剩余时间 |
| 人员 | 厨师和服务员的剩余忙碌时间、厨师是否在洗碗 |
| 时间 | 当前时间进度、当前到达率 |

medium 观测为 112 维。

## 6. 奖励

两人共享：

```
奖励 = 0.05 × (账单 + 小费)
     − 0.5 × 流失人数
     − 0.3 × 门口满员离开人数
     + 中间奖励
```

中间奖励（可整体关闭）：

| 事件 | 奖励 |
|---|---|
| 带位 | 0.1 |
| 点单 | 0.1 |
| 每道菜做好 | 0.02 |
| 每道菜上桌 | 0.05 |
| 每洗好一个盘子 | 0.01 |
| 清桌 | 0.1 |

## 8. 参数（medium）

### 回合与桌子

| 参数 | 值 | 说明 |
|---|---|---|
| episode_length | 240 | 一回合步数 |
| table_sizes | [2, 2, 2, 4, 4] | 3 张两人桌 + 2 张四人桌 |

### 顾客

| 参数 | 值 | 说明 |
|---|---|---|
| party_size_probs | [0.2, 0.4, 0.15, 0.25] | 一组 1 / 2 / 3 / 4 人的概率 |
| arrival_schedule | 见下 | 每步平均到达组数 |
| max_queue | 5 | 门口最多排几组 |

| 时间（步） | 0 | 60 | 90 | 150 | 180 | 240 |
|---|---|---|---|---|---|---|
| 到达率 | 0.05 | 0.06 | 0.16 | 0.16 | 0.06 | 0.04 |

90~150 步为午餐高峰。

## 9. 三档难度

| 参数 | easy | medium | hard |
|---|---|---|---|
| 桌子 | 2,2,2,4,4 | 2,2,2,4,4 | 2,2,2,4,4 |
| 一组人数概率 | 0.2, 0.4, 0.15, 0.25 | 0.2, 0.4, 0.15, 0.25 | 0.1, 0.35, 0.2, 0.35 |
| 到达率 | 固定 0.06 | 高峰 0.16（90~150 步） | 高峰 0.22（80~160 步） |
| 盘子 | 16 | 12 | 10（开局 3 个脏） |
| 耐心 | 30~45 | 25~40 | 18~30 |
| 甜点概率 | 0.25 | 0.25 | 0.35 |

其余参数三档相同。

## 10. 评测指标

| 指标 | 含义 |
|---|---|
| revenue | 总收入（账单 + 小费） |
| tip_total / avg_tip_rate | 小费总额 / 平均小费率 |
| customers_paid | 付款人数 |
| lost_people | 流失人数（耐心耗尽 + 门口满员） |
| seat_utilization | 座位利用率 = 入座人数 / 所坐桌子座位数 |
| cold_rate | 凉菜比例 |
| dessert_served / dessert_abandoned | 吃完甜点 / 甜点放弃的组数 |
| wasted_dishes | 做好但顾客已走的菜数 |
| plate_shortage_steps | 有菜要做但没有干净盘子的步数 |
| pass_full_steps / stoves_full_steps | 出餐口满 / 灶台满的步数 |
| chef_idle_steps / server_idle_steps | 厨师 / 服务员空闲步数 |
| avg_wait_queue | 平均排队时间（到达 → 入座） |
| avg_wait_order | 平均等点单时间（入座 → 点单） |
| avg_wait_main | 平均主菜等待（到达 → 主菜上齐） |
